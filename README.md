# E-Commerce Shopping Cart

An interactive, front-end shopping cart interface built as part of my academic coursework. This project simulates a basic e-commerce experience, allowing users to add items to a cart and dynamically calculate their total cost.

## Features
* **Product Display:** Displays a list of available products with their prices.
* **Add to Cart:** Users can add items to their shopping cart with a single click.
* **Dynamic Total Calculation:** Automatically calculates and updates the total price based on the quantities and items added to the cart.
* **Cart Management:** Users can view the items currently in their cart.
* **Responsive UI:** Clean and simple user interface styled for a smooth user experience.

## Technologies Used
* **HTML5:** For the structure of the product listings and cart layout.
* **CSS3:** For styling, layout, and visual presentation.
* **JavaScript:** For the core logic, including event handling (button clicks), storing cart items in variables, and calculating the final total.

## How to Run
1. Clone or download this repository to your local machine.
2. Open the `index.html` file in any modern web browser.
3. Start adding items to the cart to see the JavaScript calculations in action!
